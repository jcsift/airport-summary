<details>
<summary>为什么建议准备主力与备用？</summary>

机场是需要持续维护的网络服务，线路调整、节点故障、域名变化或临时拥堵都可能影响连接。主力和备用最好来自不同服务商，避免两个订阅同时受到同一运营问题影响。

| 角色 | 优先考虑 | 购买建议 |
| --- | --- | --- |
| 主力服务 | 自己常用时段的稳定性、线路质量、客服与常用节点 | 先月付测试，确认适合本地运营商后再续费 |
| 备用服务 | 低维护成本、不同入口或线路、客户端兼容 | 选择低价月付或一次性流量包，定期确认订阅仍可用 |

</details>

<details>
<summary>机场与商业 VPN 有什么区别？</summary>

“VPN 机场”是常见搜索说法，但机场订阅与商业 VPN 并不完全相同：

- **商业 VPN**通常提供自有客户端和统一账户体系，安装后直接登录使用。
- **机场订阅**通常提供节点和订阅地址，需要导入 Clash、v2rayN、Shadowrocket、Sing-box 等兼容客户端。

两者都不能仅凭名称判断速度、隐私或稳定性。机场体验还会受到本地运营商、入口线路、节点负载、客户端规则和使用时段影响。不了解客户端时，可以先查看[翻墙科学上网客户端教程汇总](https://eoht.net/serve/antiwall/summary)。

</details>

<details>
<summary>常见问题</summary>

**年付折合月价和真正的月付有什么区别？**

年付折合月价只是“年付总额 ÷ 12”的比较方式，购买时仍需一次支付全年费用；真正月付可以按月停止续费，首次尝试时资金风险更低。本页统一展示最便宜年付的实际总额，月付套餐请在对应详情页核对。

**一次性不限时流量包等于无限流量吗？**

不等于。一次性不限时通常表示购买固定总流量后不按月重置，用完为止；无限流量通常是按月或按年续费，但可能仍有速率、公平使用或设备限制。具体规则以套餐说明为准。

**第一次购买应该选择多少流量？**

先查看手机和电脑过去一个月的实际网络用量，再区分哪些流量需要经过代理。网页与 AI 问答通常比高清视频节省流量；视频清晰度、下载、多设备共享和节点倍率都会显著增加消耗。首次购买不必一次覆盖全年，留出调整空间更重要。

**标注 IPLC 或 IEPL 就一定稳定吗？**

不一定。线路类型只说明连接路径的一部分，入口质量、服务器负载、带宽配置、本地运营商和客户端规则同样会影响结果。宣传页和测速图可以作为参考，最终仍应以自己的网络和常用时段测试为准。

**Netflix 或 ChatGPT 解锁结果会一直不变吗？**

不会。流媒体和 AI 服务可能调整地区、账号与 IP 风控策略，机场也可能更换落地服务器。详情页中的解锁图只能代表记录时的节点结果，购买后需要测试实际分配到的节点。

**订阅导入失败时先检查什么？**

先确认订阅没有过期、复制时没有缺失字符，并使用服务商支持的客户端和较新版本；随后检查订阅更新、系统 VPN 权限、时间设置和网络连接。不同平台的操作入口可在[客户端教程汇总](https://eoht.net/serve/antiwall/summary)中查找。

</details>
